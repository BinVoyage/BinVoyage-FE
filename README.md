### 🛠 Tech Stack
- React Native
- React Native WebView
- React
- Typescript
- Zustand
- Styled-Components
- Kakao Maps API
- Google & Apple Social Login (OAuth)

### 🌟 Features
- **소셜 로그인**  
  - Google & Apple OAuth를 통한 간편 로그인
 
- **서울 내 쓰레기통 위치 확인**
  - 서울시 공공데이터 활용 & 가공
    
- **현재 위치 및 쓰레기통 마커 표시**
  - Kakao Maps API를 활용한 지도 렌더링 및 마커 표시  
  - React Native WebView를 활용한 원활한 지도 연동 
 
- **신규쓰레기통 제보 - 이미지 업로드 (AWS S3 연동)**  
  - `react-native-image-crop-picker`로 카메라 / 갤러리에서 이미지 선택 (권한 체크 포함)  
  - 서버에서 S3 업로드용 Presigned URL 받아서 활용  
  - `react-native-blob-util`을 이용한 파일 업로드
 
- **스탬프 획득 애니메이션**
  - 스탬프 획득 시 `Lottie` 라이브러리를 사용하여 생동감 있는 애니메이션 효과 적용
